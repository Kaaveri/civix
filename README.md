# Civix

**Civix** is a community engagement and civic communication platform developed as part of the **Infosys Internship Program**.

The platform enables **citizens** and **community officials** to communicate effectively, collaborate on local issues, and participate in decision-making for community development.

This was a **team project**, and this repository is my personal copy showcasing my contributions, primarily focused on **backend development**.

---

## Project Overview

Civix is designed to bridge the communication gap between citizens and local officials by providing a digital platform where:

- Citizens can raise petitions or complaints regarding community issues
- Other citizens can support petitions through signatures
- Officials can review petitions and provide status updates or resolutions
- Officials can create community polls to gather public opinion
- Citizens can participate in polls and contribute to community decisions

The platform promotes transparency, participation, and faster resolution of local concerns.

---

## Key Features

### Citizen Portal
- User registration and secure login
- Create and submit petitions/complaints
- Browse and support existing petitions through signatures
- Track petition status and official responses
- Participate in official community polls

### Official Portal
- Separate official login system
- Review submitted petitions
- Approve, reject, or update petition status
- Provide feedback/resolution updates
- Create and manage public opinion polls

### Core Functionality
- Role-based authentication (Citizen / Official)
- Petition signature tracking
- Poll creation and voting system
- Database-driven data management
- Responsive web interface

## Installation

### Clone the repository

```bash
git clone https://github.com/Kaaveri/civix.git
```

### Navigate into the project folder

```bash
cd civix
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm start
```
